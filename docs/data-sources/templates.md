# certsecure_templates (Data Source)

Lists the certificate templates available on a CA in CertSecure.

Use a value from `names` as `template` in `certsecure_certificate`. For Microsoft CA, `names` holds template names (e.g. `WebServer`), while `templates[*].friendly_name` holds display names (e.g. `Web Server`), which enrollment does not accept.

## Example Usage

```terraform
data "certsecure_templates" "issuing" {
  ca_name = "Issuing-CA-01"
}

# Template names to use as certsecure_certificate.template.
output "template_names" {
  value = data.certsecure_templates.issuing.names
}

# Template details, keyed by display name.
output "template_validity" {
  value = { for t in data.certsecure_templates.issuing.templates : t.friendly_name => t.validity_period }
}
```

## Schema

### Required

### Read-Only

- `names` (List of String) Template names accepted by `certsecure_certificate.template`, sorted.
- `templates` (Attributes List) Template details. Empty when CertSecure has no template details for the CA (for example when its connector is offline). (see [below for nested schema](#nestedatt--templates))

- `validity_period` (String) Validity period, e.g. `2 Years`.
