# certsecure_certificate (Data Source)

Reads an existing certificate from CertSecure by its enrollment ID, for example one requested in the CertSecure portal or by another Terraform configuration. The data source never issues, renews or revokes a certificate.

To manage a certificate's lifecycle (renewal and revocation) with Terraform, use the [certsecure_certificate resource](https://registry.terraform.io/providers/encryption-consulting-llc/certsecure/latest/docs/resources/certificate) instead, or import
the certificate into it.

## Example Usage

```terraform
# Read a certificate that already exists in CertSecure, for example one
# requested in the CertSecure portal, by its enrollment ID (eid).
data "certsecure_certificate" "web" {
  enrollment_id = 1501
}

output "web_certificate_expires" {
  value = data.certsecure_certificate.web.not_after
}

output "web_certificate_status" {
  value = data.certsecure_certificate.web.status
}
```

## Important Notes

- **No private key.** The data source returns the certificate and its chain only. A destination that needs the key,
  such as `aws_acm_certificate`, takes it from where the key and CSR were created.
- **Only issued certificates can be read.** A request that is pending or awaits approval has no certificate yet, and
  reading it fails with its status. Revoked and expired certificates can be read; check `status` and `not_after`.
- **Permissions.** The CertSecure user of the API token needs *View Enrollment Database*.

## Schema

### Required

- `enrollment_id` (Number) CertSecure enrollment ID (`eid`) of the certificate, for example `certsecure_certificate.example.enrollment_id` from another configuration.

### Read-Only

- `ca_name` (String) Name of the CA that issued the certificate.
- `certificate_pem` (String) The certificate, PEM encoded.
- `chain_pem` (String) The issuing CA chain as concatenated PEM certificates, issuer first. Does not include the certificate itself.
- `common_name` (String) Subject common name of the certificate.
- `dns_names` (List of String) DNS names in the certificate's subject alternative names.
- `id` (String) The enrollment ID, as a string.
- `not_after` (String) End of the certificate validity period (RFC 3339).
- `not_before` (String) Start of the certificate validity period (RFC 3339).
- `serial_number` (String) Certificate serial number as lowercase hexadecimal.
- `status` (String) Enrollment status reported by CertSecure, e.g. `active`, `expired` or `revoked`.
- `tags` (List of String) Tags recorded on the certificate in CertSecure.
- `template` (String) Certificate template the certificate was issued with.
