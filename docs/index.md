# CertSecure Provider

## Overview

The Terraform provider for [CertSecure Manager](https://www.encryptionconsulting.com/) enables certificate issuance
through CertSecure with HashiCorp Terraform. The provider is a client of the CertSecure REST API only; CertSecure
reaches the certificate authority through its connectors:

```
Terraform → terraform-provider-certsecure → CertSecure API → CertSecure connector → CA (e.g. Microsoft CA / AD CS)
```

Below are the currently supported resources and data sources:

| CertSecure Resource          | Terraform Resource                                                                                                               |
|------------------------------|----------------------------------------------------------------------------------------------------------------------------------|
| Certificate (CSR enrollment) | [certsecure_certificate](https://registry.terraform.io/providers/encryption-consulting-llc/certsecure/latest/docs/resources/certificate) |
| Available CAs                | [certsecure_cas](https://registry.terraform.io/providers/encryption-consulting-llc/certsecure/latest/docs/data-sources/cas)       |
| CA templates                 | [certsecure_templates](https://registry.terraform.io/providers/encryption-consulting-llc/certsecure/latest/docs/data-sources/templates) |
| Certificate lookup           | [certsecure_certificate](https://registry.terraform.io/providers/encryption-consulting-llc/certsecure/latest/docs/data-sources/certificate) (data source) |

Delivery to the systems that use the certificate is done by their own Terraform providers. Guides:

- [AWS Certificate Manager](https://registry.terraform.io/providers/encryption-consulting-llc/certsecure/latest/docs/guides/aws-acm) (with an Application Load Balancer)
- [Azure Key Vault](https://registry.terraform.io/providers/encryption-consulting-llc/certsecure/latest/docs/guides/azure-key-vault)
- [Kubernetes](https://registry.terraform.io/providers/encryption-consulting-llc/certsecure/latest/docs/guides/kubernetes) (TLS secret for an Ingress)
- [Protecting the private key in Terraform state](https://registry.terraform.io/providers/encryption-consulting-llc/certsecure/latest/docs/guides/state-security)
- [Troubleshooting](https://registry.terraform.io/providers/encryption-consulting-llc/certsecure/latest/docs/guides/troubleshooting): errors and warnings, approvals, timeouts

## Authentication

The provider authenticates with a CertSecure API token, sent as a bearer token. Tokens are created in CertSecure
(API Token Management) and are not managed by this provider. The token's role determines which CAs and templates
it can use. The provider validates the token when it is configured and fails early if it is invalid or expired.

Prefer environment variables over hard-coding credentials:

```shell
export CERTSECURE_URL="https://certsecure.example.com"
export CERTSECURE_TOKEN="..."
```

Environment variables: `CERTSECURE_URL`, `CERTSECURE_TOKEN`, `CERTSECURE_CA_BUNDLE`. Attributes set in the provider
block override environment variables.

## Example Usage

```terraform
terraform {
  required_providers {
    certsecure = {
      source = "encryption-consulting-llc/certsecure"
    }
  }
}

# The token is read from the CERTSECURE_TOKEN environment variable.
# The URL can also come from CERTSECURE_URL.
provider "certsecure" {
  url = "https://certsecure.example.com"
}
```

## Schema

### Optional

- `ca_bundle_pem` (String) PEM-encoded CA certificate(s) to trust for TLS connections to CertSecure, in addition to the system trust store. Can also be set with the `CERTSECURE_CA_BUNDLE` environment variable.
- `insecure_skip_verify` (Boolean) Skip TLS certificate verification of the CertSecure API. **For lab use only.** Defaults to `false`.
- `request_timeout` (String) Timeout for each HTTP request to CertSecure, as a Go duration string. Defaults to `"60s"`.
- `token` (String, Sensitive) CertSecure API token, without the `Bearer ` prefix. Tokens are created in CertSecure (API Token Management); the provider never creates them. Can also be set with the `CERTSECURE_TOKEN` environment variable.
- `url` (String) Base URL of the CertSecure API, e.g. `https://certsecure.example.com`. Can also be set with the `CERTSECURE_URL` environment variable.
