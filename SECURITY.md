# Security Policy

## Reporting a Vulnerability

Please do not report security vulnerabilities through public GitHub issues, discussions or pull requests.

Report them privately through GitHub's
[private vulnerability reporting](https://github.com/Encryption-Consulting-LLC/terraform-provider-certsecure/security/advisories/new)
(**Security** tab, **Report a vulnerability**). Include the provider version, the steps to reproduce and the impact you
expect. Never include API tokens, private keys, certificate bodies or internal host names.

The maintainers acknowledge reports and keep you informed until a fix is released. Fixes are published as a new
provider release and announced in a GitHub security advisory.

## Supported Versions

Security fixes are released for the latest minor version of the provider. Upgrade to the latest release to receive
them.

## Scope

This policy covers the Terraform provider in this repository. Vulnerabilities in CertSecure Manager itself should be
reported to Encryption Consulting through your support channel or the
[contact page](https://www.encryptionconsulting.com/contact-us/).
